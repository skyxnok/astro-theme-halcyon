卫生统计学是运用统计学原理与方法，研究医学卫生领域中数据的收集、整理、分析和推断的科学。绪论一章是整个学科的基石，重点厘清「总体/样本」「同质/变异」「参数/统计量」「概率/频率」这一批基础概念。把这一章吃透，后面学描述统计和推断统计才不会晕。

## 一、总体与样本：研究对象从哪来

**总体（population）**：根据研究目的所确定的、所有同质观察单位某项指标实际值的集合。例如「2026 年某市 3 岁男童的身高」，总体就是该市所有 3 岁男童身高的全体。

**样本（sample）**：按照随机化原则，从总体中抽取的有代表性的一部分观察单位，其实测值构成样本。

**样本含量（sample size）**：样本所包含的个体（或个体值）个数，一般记为 n。

> 关键点：总体是由**研究目的**划定的——先定目的，再定总体，然后才谈抽样。

## 二、抽样与抽样研究：为什么要抽样本

**抽样（sampling）**：从总体中抽取有代表性的一部分样本的过程。

**抽样研究（sampling study）**：从确定的同质总体中随机抽取部分样本进行观察，用样本信息来推断总体特征的研究方法。

**统计推断（statistical inference）**：由样本的现象推断所研究总体的特征，即分析样本数据，获得关于总体的知识。

整章的一条主线：

```
总体（研究目的确定） → 随机抽样 → 样本 → 统计分析 → 统计推断 → 总体特征
```

绝大多数医学研究都是抽样研究：因为总体往往「无限」或「难以穷尽」（如所有高血压患者），只能通过样本去推断。

## 三、同质与变异：医学资料的两个基本特征

**同质（homogeneity）**：研究对象在一定范畴内，各种可能影响主要观察指标的其它因素处于相同或非常相似的情况。具有相同性质的观察单位称为同质的，否则为异质的。

**变异（variation）**：同质基础上的各观察单位间的差异。

例如研究某药的降压效果：「同质」指纳入的都是确诊高血压、年龄性别等混杂因素相近的患者；但即便如此，每个人的血压下降值仍不同——这就是「变异」。

> 同质是统计分析的前提，变异是统计分析的对象。统计学的价值，就是在变异中找规律。

## 四、统计描述与统计推断：研究的两个层次

**统计描述（statistical description）**：用统计指标、统计表、统计图等方法，对样本资料的数量特征及其分布规律进行描述。

**统计推断（statistical inference）**：用样本信息推断总体特征，包括两个部分：

- **参数估计**：用样本统计量估计总体参数
- **假设检验**：先提出假设、再检验，判断差异是否由抽样误差引起

## 五、参数与统计量、变量与变量值

**参数（parameter）**：根据总体变量值统计计算出来、描述总体特征的统计指标，如总体均数 μ、总体标准差 σ。

**统计量（statistic）**：根据样本个体值统计计算出来、描述样本特征的统计指标，如样本均数 x̄、样本标准差 s。

| 项目 | 参数 | 统计量 |
| --- | --- | --- |
| 计算依据 | 总体变量值 | 样本个体值 |
| 描述对象 | 总体特征 | 样本特征 |
| 常用符号 | μ、σ | x̄、s |
| 是否已知 | 一般未知（是推断的目标） | 由样本算出 |

**变量（variable）**：观察单位的观察指标，其变异性表现为取值的大小，如身高、体重。

**变量值（variable value）**：观察单位的观察值，如某人身高 118cm、体重 26kg。

## 六、变量的类型

按性质与取值方式，变量可分为两大类：

- **数值变量（定量变量）**：取值为定量的
  - 连续变量：可在实数范围内任意取值，如身高、体重、血压
  - 离散变量：只能取整数，如人数、脉搏次数
- **分类变量（定性变量）**
  - 无序分类（计数资料）：类别间无等级，如性别、血型
  - 有序分类（等级变量）：类别间有程度或等级差异，如疗效「痊愈/好转/无效」、尿糖「±/+ /++/+++」

> 你整理的「连续变量」「等级变量」分别就是这两大类的代表。

## 七、误差与抽样误差

**误差（error）**：观察值（X）与实际值（μ）之差。

**抽样误差（sampling error）**：由抽样造成的样本统计量和总体参数的差别，以及样本统计量之间的差别。

抽样误差是抽样研究固有的、不可避免的，但它有一定规律可循：样本含量越大、个体变异越小，抽样误差越小。这正是后续推断统计能够「算账」的基础。

## 八、随机事件、概率与频率

**随机事件（random event）**：随机试验中可能出现的各种结果。即在一定条件下有多种可能发生的结果，而究竟发生哪一个结果不能肯定，又称偶然事件。

**概率（probability）**：描述随机事件发生可能性大小的一种度量，常用 P 表示。

**小概率事件**：当随机事件 A 的概率 P(A) ≤ α，习惯上取 α = 0.05 时，就称 A 为小概率事件；其统计学意义是——小概率事件在一次随机试验中不可能发生。这也是假设检验中「拒绝 H₀」的依据之一。

**频率（frequency）**：在 n 次试验中，若事件 A 发生的次数为 m，则：

```
fₙ(A) = 事件 A 发生的次数 m / 试验的总次数 n
```

m 称为事件 A 在 n 次试验中的频数，fₙ(A) 称为事件 A 在 n 次试验中发生的频率。

> 频率 ≠ 概率：频率是试验结果，随试验次数波动；概率是理论值。当试验次数 n 足够大时，频率会稳定地趋近于概率。

## 九、一张表理清易混概念

| 容易混淆 | 区别要点 |
| --- | --- |
| 总体 vs 样本 | 总体是研究目的确定的全体；样本是随机抽取的代表性部分 |
| 同质 vs 变异 | 同质是其它影响因素相近；变异是同质个体间仍有差异 |
| 参数 vs 统计量 | 参数来自总体（μ、σ）；统计量来自样本（x̄、s） |
| 变量 vs 变量值 | 变量是指标（身高）；变量值是其取值（118cm） |
| 误差 vs 抽样误差 | 误差 = X − μ；抽样误差由抽样引起，是误差的一种 |
| 概率 vs 频率 | 概率是理论值；频率是试验值，n 足够大时频率趋近概率 |
| 统计描述 vs 统计推断 | 描述管「样本自身」；推断管「由样本推向总体」 |

## 小结

绪论的核心是建立「总体—样本—推断」的思维框架：从同质总体中随机抽样，描述样本资料，再用统计推断（参数估计 + 假设检验）回答关于总体的科学问题。全程要牢记变异与抽样误差客观存在——统计学的意义，正是在变异中找规律、在误差下做推断。

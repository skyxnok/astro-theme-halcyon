拿到一组资料后，第一步要做的是**统计描述**：用频数表、直方图把数据的分布形态看清楚，再用集中趋势指标（平均水平）和离散趋势指标（变异程度）把数据特征量化。这一章是描述统计的核心，也是后续推断统计的基础。

## 一、频数分布表与直方图

**组距（class interval）**：多用于连续型定量资料编制频数分布表，把数值分成若干组段，每组的区间宽度就是组距：

$$i = \frac{\text{极差（全距）}}{\text{拟分组数}}$$

编制频数分布表的步骤：

1. 求极差（全距）R
2. 确定组数与组距 $i = R / \text{拟分组数}$
3. 划分组段（注意组段通常「上限不在内」，即半开半闭区间）
4. 清点各组频数，绘制频数分布表

**全距 / 极差（range）R**：反映一组数据波动的总跨度，是最简单的离散指标：

$$R = X_{\max} - X_{\min}$$

- 优点：计算简单，直观
- 缺点：只用到最大、最小两个数值，容易受极端值影响，不能反映中间数据的分布情况
- 用途：制作频数表的第一步——先算极差，才能确定组距

**直方图（histogram）**：以组段为底边、频数为高的矩形图，矩形面积与频数成正比。适用于大样本连续型定量资料，可直观判断分布形态（正态还是偏态），是检查资料分布的第一步工具。

## 二、正态分布与偏态分布（考试重点）

**正态分布**：左右对称，中间高、两侧低，两侧尾巴长度差不多，均数 ≈ 中位数。

**偏态分布**：分布不对称，两侧尾巴长短不一样，分为**正偏态（右偏）**和**负偏态（左偏）**。

> 核心记忆：**尾巴在哪一侧，就叫哪一侧偏态。**

### 1. 正偏态（右偏态）⭐考试高频

- 长尾巴拖向**右侧**（数值大的一边）
- 特点：少数个体数值特别大，大部分数据集中在小数值这边
- 均数 ＞ 中位数
- 现实例子：传染病潜伏期、住院天数、血清抗体滴度、部分毒物剂量

> 例：多数人潜伏期 2–3 天，极少数人潜伏期几十天，右侧拉出长长的尾巴 → 正偏态。

### 2. 负偏态（左偏态）

- 长尾巴拖向**左侧**（数值小的一边）
- 特点：少数数值特别小，大多数集中在大数值一侧
- 均数 ＜ 中位数
- 例子：老年人群寿命——大部分人年龄大，少数人早亡，左侧尾巴长

### 3. 三种分布对比速记

| 分布类型 | 对称性 | 尾巴位置 | 均数与中位数关系 | 统计描述选用指标 |
| --- | --- | --- | --- | --- |
| 正态分布 | 左右对称 | 两侧尾巴差不多 | 均数 ≈ 中位数 | 均数 ± 标准差 |
| 正偏态（右偏） | 不对称 | 尾巴向右（大值） | 均数 ＞ 中位数 | 中位数、四分位数间距 Q |
| 负偏态（左偏） | 不对称 | 尾巴向左（小值） | 均数 ＜ 中位数 | 中位数、四分位数间距 Q |

> 考点口诀：正态看均数标准差；**偏态资料不能用均数和标准差**，要用中位数 M、四分位数间距 Q。

### 4. 偏态资料的处理

1. **描述集中、离散趋势**：不用均数标准差，用中位数 + 四分位数间距
2. **频数表**：经常用不等组距（如潜伏期，数值大的那一组组距拉大）
3. **统计检验**：
   - 不满足正态时不用 t 检验，改用非参数检验（秩和检验）
   - 部分资料可以做对数转换，转换成近似正态后再做参数检验

### 5. 易混考点

1. **偏态看尾巴，不是看高峰**：高峰在哪边不决定偏态名称。正偏态是高峰靠左、尾巴向右延伸
2. **开口资料**（如「＞100」「＜20」这类只有单侧界限的资料）大多是偏态分布，且**算不出极差**
3. **几何均数 G** 多用于正偏态的等比资料、对数正态资料（如抗体滴度）

## 三、集中趋势指标（平均水平）

集中趋势描述一组数据的「平均水平」或「典型水平」，常用指标有算术均数、几何均数、中位数。

### 1. 算术均数（mean）X̄

**原始数据公式**：

$$\bar{X} = \frac{\sum X}{n}$$

- $\sum X$：所有观察值求和
- $n$：样本例数
- X̄ 读作「X 拔」

**频数表（加权法）公式**：分组频数表资料，用各组组中值代表本组全部数值：

$$\bar{X} = \frac{\sum fX}{\sum f}$$

- $f$：各组频数
- $X$：各组组中值
- $\sum f = n$：总例数

适用与注意：

- **适用**：正态、近似正态分布（身高、体重、血红蛋白）
- **不适用**：偏态分布、开口资料（潜伏期、住院天数，此时用中位数）
- **受极端值影响很大**：出现特大 / 特小值，算术均数会被拉高或拉低

### 2. 几何均数（geometric mean）G

$$G = \sqrt[n]{X_1 X_2 \cdots X_n}$$

实际计算常用对数转换：

$$G = \lg^{-1}\left(\frac{\sum \lg X}{n}\right)$$

**频数表加权法（分组资料）**：

$$G = \lg^{-1}\left(\frac{\sum f \cdot \lg X}{\sum f}\right)$$

适用条件：

1. **等比数列资料**：如抗体滴度 1:2、1:4、1:8、1:16
2. **对数正态分布**：正偏态资料，取对数后变成正态分布

注意：

- **不能用**：资料中有 0、有负数的资料（无法取对数）
- 算术均数会被特大值拉高，**几何均数受极端值影响更小**

### 3. 中位数（median）M

**原始资料公式**：

- n 为奇数：$$M = X_{\frac{n+1}{2}}$$
- n 为偶数：取中间两个数的平均值
  $$M = \frac{X_{n/2} + X_{n/2+1}}{2}$$

**频数表法（百分位数法，考试高频）**：中位数就是第 50 百分位数：

$$M = P_{50} = L + \frac{i}{f_M}\left(\frac{n}{2} - F_L\right)$$

- $L$：中位数所在组段的下限
- $i$：组距
- $f_M$：中位数所在组段频数
- $F_L$：中位数所在组之前的累计频数
- $n$：总例数

四分位数：$P_{25} = Q_1$，$P_{75} = Q_3$

**四分位数间距**：

$$Q = P_{75} - P_{25}$$

### 4. 集中趋势指标对比

| 指标 | 符号 | 适用资料 |
| --- | --- | --- |
| 算术均数 | X̄ | 正态分布 |
| 几何均数 | G | 等比、对数正态（抗体滴度） |
| 中位数 | M | 偏态、开口、分布不明 |

## 四、离散趋势指标（变异程度）

一组数据中个体值之间的差异称为**变异**。描述变异程度的常用指标有极差、四分位数间距、方差、标准差和变异系数，它们也称**离散度测量指标**。集中趋势 + 离散趋势合起来，才能完整描述一组资料。

### 1. 极差 R

即全距，见第一节。只看两头，受极端值影响大，仅作初步了解。

### 2. 四分位数间距 Q

$$Q = P_{75} - P_{25}$$

- 不受极端值影响
- 与中位数配套使用，适合偏态、开口资料

### 3. 方差（variance）s²

各个观察值与均数的离均差平方和除以自由度 $n-1$，单位是原指标单位的平方：

$$s^2 = \frac{\sum (X - \bar{X})^2}{n - 1}$$

- $\sum (X - \bar{X})^2$：离均差平方和
- $n - 1$：自由度 $\nu$

### 4. 标准差（standard deviation）s

方差开平方根，最常用的离散指标，单位和原始数据一致：

$$s = \sqrt{\frac{\sum (X - \bar{X})^2}{n - 1}}$$

- 正态资料的报告格式：$\bar{X} \pm s$
- 标准差越大，个体变异越大
- **注意**：受计量单位、均数大小影响，不能直接比较两组单位不同的资料的离散程度

### 5. 变异系数（coefficient of variation）CV

消除量纲和均数大小的影响，用于比较两组资料的变异程度：

$$CV = \frac{s}{\bar{X}} \times 100\%$$

**两大使用场景（考试高频）**：

1. **单位不同的两组资料**比较变异：如身高（cm）vs 体重（kg）
2. **均数相差悬殊的两组资料**比较变异：如成人身高 vs 儿童身高

注意：CV 没有单位；只用于正态资料；不能用于偏态。

### 6. 离散趋势指标对比

| 指标 | 符号 | 要点 | 适用资料 |
| --- | --- | --- | --- |
| 极差（全距） | R | 最大值−最小值，只看两头，受极端值影响大 | 初步看范围，不推荐正式分析 |
| 四分位数间距 | Q = P₇₅ − P₂₅ | 不受极端值影响 | 偏态、开口资料 |
| 方差 | s² | 单位是原单位平方，实际少直接报告 | 正态资料计算的中间量 |
| 标准差 | s | 单位与原数据一致，最常用 | 正态、近似正态，X̄ ± s |
| 变异系数 | CV | 无单位，用于对比变异大小 | 正态资料，单位不同 / 均数差距大时比较 |

## 五、数据核查与离群值探索

资料整理阶段先做质量核查，再进入统计分析。

**逻辑核查**（7 项）：

1. 检查变量类型和性质
2. 核查变量值范围
3. 有效值检查
4. 一致性检查
5. 唯一性检查
6. 完整性检查
7. 交叉检查

**离群值（outlier）探索**的 4 种方法：

1. 通过频数分布表或直方图初步判断
2. 利用箱式图判断
3. 通过统计检验判断
4. 结合其他变量信息判断

## 六、常用统计图

| 统计图 | 适用资料与用途 |
| --- | --- |
| 直方图 | 连续型定量资料，看分布形态（正态 / 偏态） |
| 箱式图 | 显示中位数、四分位数间距与离群值，适合多组资料对比分布 |
| 饼图 | 分类资料，表示各部分构成比（占整体的百分比），组成部分不宜过多 |
| 条图 | 用等宽直条的高度比较分类资料各类别的数值大小（分单式、复式条图） |
| 热图 | 用颜色深浅表示矩阵数值大小，适合大矩阵资料（如相关矩阵、表达谱） |

## 小结与速记

- **两个维度看资料**：集中趋势（平均水平）＋ 离散趋势（变异程度）
- **分布决定指标**：正态资料用 X̄ ± s；偏态、开口资料用 M 和 Q；等比、对数正态资料用 G
- **偏态看尾巴**：尾巴在哪一侧，就叫哪一侧偏态
- **CV 两大场景**：单位不同 / 均数相差悬殊的两组资料比较变异
- **标准差 vs 变异系数**：标准差有单位不能跨组直接比，CV 无单位可以比
